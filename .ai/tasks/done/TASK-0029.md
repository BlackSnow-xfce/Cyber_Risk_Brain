## Ziel

Die kanonischen fachlichen Entitäten von PredatorAI identifizieren, eindeutig einer bereits definierten Domäne zuordnen und damit erstmals eine gemeinsame fachliche Sprache der Plattform dokumentieren.

Der Task beschreibt ausschließlich fachliche Begriffe und deren Bedeutung. Er führt keine Modelle oder Implementierungsdetails ein.

## Scope

Genau ein technologieunabhängiges Architekturartefakt `.ai/architecture/CANONICAL-ENTITIES.md` erstellen.

Für jede bereits definierte kanonische Domäne dokumentieren:

* Canonical Entities
* Kurzbeschreibung jeder Entität
* fachlicher Zweck jeder Entität
* eindeutige Zugehörigkeit zu genau einer Domäne
* fachlicher Owner ausschließlich über diese Domäne

Das Artefakt definiert eine eindeutige Ubiquitous Language. Synonyme, rollenbezogene Anzeigenamen und historisch konkurrierende Begriffe sind, soweit für Eindeutigkeit erforderlich, ohne technische Migration abzugrenzen.

## Architekturregeln

* Die bestehende Liste kanonischer Domänen bleibt unverändert.
* Die bestehende Domain Ownership bleibt unverändert.
* Jede Canonical Entity gehört genau einer kanonischen Domäne.
* Fachlicher Owner einer Entität ist ausschließlich ihre Owner-Domäne.
* Eine Entität wird nur über stabile fachliche Identität und Lebenszyklus als solche eingeordnet; konkrete Attribute werden nicht definiert.
* Gleichnamige oder ähnliche Begriffe dürfen keine parallele fachliche Ownership begründen.
* Workspaces, Rollen, Seiten und Präsentationsbegriffe sind keine Canonical Entities.
* Explainability und Execution Trace bleiben die in den ACCEPTED ADRs definierten abgeleiteten beziehungsweise technischen Architekturartefakte.
* `DecisionResult` bleibt gemäß ADR-0001 das kanonische Ergebnis einer abgeschlossenen Decision.
* Die Beschreibung bleibt technologie-, workspace-, rollen- und implementierungsunabhängig.
