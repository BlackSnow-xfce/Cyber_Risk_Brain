Status: DONE
Review: PASS / APPROVED

## Implementation

Implemented the minimal immutable `AIModelEgressPolicy 1.0` contract required
by ADR-0014. It represents an explicit typed AI purpose, canonical resource
type, permitted classifications, an explicit typed field allowlist, an
ALLOW/DENY decision and a policy source reference.

The initial purpose is `FINDING_EXPLANATION`. The selected allowlist is limited
to the existing safe Finding explanation inputs `finding.title` and
`finding.vendor_severity`; no complete Finding serialization is authorized.
The canonical `AIResourceType` and `AIContextClassification` types are reused.

## Security semantics

- ALLOW requires non-empty classifications and a non-empty typed field
  allowlist.
- DENY has no effective permissions.
- Wildcards, `all`, arbitrary strings and natural-language field identifiers
  are rejected.
- Missing classifications never become PUBLIC.
- Field and classification checks are deterministic and immutable.
- The contract does not authorize retrieval, context admission, provider or
  model selection, payload construction or model egress execution.
