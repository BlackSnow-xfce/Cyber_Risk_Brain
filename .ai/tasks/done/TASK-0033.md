## Ziel

## Scope

Genau ein technologieunabhängiges Architekturartefakt `.ai/architecture/DOMAIN-DEPENDENCIES.md` erstellen.

Für jede kanonische Domäne dokumentieren:

* Domain Name
* eindeutiger fachlicher Layer
* Allowed Dependencies
* Forbidden Dependencies
* Dependency Direction
* fachliche Begründung

Zusätzlich eine vollständige Domain-Dependency-Matrix erstellen, die für jede geordnete Kombination kanonischer Domänen eindeutig ausweist, ob eine fachliche Abhängigkeit erlaubt oder verboten ist.

## Architekturregeln

* Die bestehenden Domain Boundaries, Ownership-Verantwortungen, Aggregate Boundaries und Aggregate Relationships bleiben unverändert.
* Jede der zwölf kanonischen Domänen wird genau einem fachlichen Layer zugeordnet.
* Die Layer-Reihenfolge muss eine eindeutige azyklische fachliche Abhängigkeitsrichtung festlegen.
* Allowed Dependencies müssen durch bestehende Beziehungen aus `AGGREGATE-RELATIONSHIPS.md` begründet sein.
* Forbidden Dependencies umfassen alle übrigen domänenübergreifenden Richtungen und müssen als Schutz gegen Ownership-Umkehr und Rückreferenzen erklärt werden.
* Eine erlaubte Domain-Abhängigkeit überträgt keine Ownership und erweitert keine Aggregate-Grenze.
* Domänen dürfen nicht von sich selbst als domänenübergreifender Abhängigkeit abhängen.
* Keine Regel darf eine Rückreferenz gegen die definierte Layer-Richtung erlauben.
* Der fachliche Domain-Graph muss azyklisch bleiben.
* Die Matrix beschreibt ausschließlich fachliche Zulässigkeit, keine Kommunikation, Ausführung oder Datenübertragung.
* Decision, Evidence, Explainability und Execution Trace bleiben gemäß ADR-0001 bis ADR-0006 getrennt.
* Die Beschreibung bleibt technologie-, workspace-, rollen- und implementierungsunabhängig.

## Dependency-Matrix

Die vollständige Matrix muss:

* alle zwölf Domänen sowohl als Source als auch als Target enthalten,
* die Diagonale eindeutig als `SELF` kennzeichnen,
* jede domänenübergreifende Zelle eindeutig als `ALLOWED` oder `FORBIDDEN` kennzeichnen,
* mit den dokumentierten Allowed und Forbidden Dependencies übereinstimmen,
* und jede `ALLOWED`-Zelle auf mindestens eine bestehende Aggregate-Beziehung zurückführen können.
