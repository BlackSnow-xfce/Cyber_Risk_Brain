## Ziel

Die kanonischen Value Objects von PredatorAI identifizieren und technologieunabhängig dokumentieren.

Value Objects beschreiben unveränderliche fachliche Werte und ergänzen gemeinsam mit den bereits identifizierten Canonical Entities die Ubiquitous Language des Domänenmodells. Dieser Task definiert ausschließlich fachliche Begriffe und ihre Einordnung, keine Implementierungsstruktur.

## Scope

Genau ein technologieunabhängiges Architekturartefakt `.ai/architecture/CANONICAL-VALUE-OBJECTS.md` erstellen.

Für jedes identifizierte kanonische Value Object dokumentieren:

* eindeutiger Name
* fachlicher Zweck
* Kurzbeschreibung
* Zugehörigkeit zu genau einer bestehenden kanonischen Domäne
* Begründung, warum der Begriff ein Value Object und keine Entität ist
* Begründung, warum der fachliche Wert unveränderlich ist

## Architekturregeln

* Die bestehenden Domain Boundaries, Ownership-Verantwortungen und Canonical Entities bleiben unverändert.
* Jedes Value Object ist genau einer kanonischen Domäne zugeordnet.
* Ein Value Object besitzt keine eigenständige fachliche Identität und wird ausschließlich durch seine fachliche Bedeutung beschrieben.
* Value Objects werden als unveränderliche fachliche Werte eingeordnet; konkrete technische Unveränderlichkeit wird nicht implementiert.
* Ein bereits als Canonical Entity definierter Begriff darf nicht zusätzlich als Value Object klassifiziert werden.
* Gleichnamige oder ähnliche Begriffe dürfen keine parallele fachliche Bedeutung begründen.
* Bestehende kanonische Verträge aus ADR-0001 bis ADR-0006 bleiben verbindlich.
* Workspaces, Rollen, Seiten und Darstellungsbegriffe sind keine Value Objects.
* Die Beschreibung bleibt technologie-, workspace-, rollen- und implementierungsunabhängig.
