## Objective

Implement the smallest controlled target-side `PROCESS_ACTIVITY` runtime
signal adapter. A typed process signal becomes `SecurityObservationInput`
and passes through the existing TASK-0102 Creation Boundary to produce
`SecurityObservation 1.0`.

The observation states only that the represented process activity was observed
by the configured source on the bound target. It does not assert exploit
success, RCE, command execution, compromise, incident confirmation, or
verification.
