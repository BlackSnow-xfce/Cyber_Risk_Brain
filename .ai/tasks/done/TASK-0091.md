## Implementation

Implemented the deterministic provider-independent `AIOutputDisclosurePolicy`
over the existing `AIOutputDisclosureDecision 1.0` contract.

The initial policy is deliberately narrow: `FINDING_EXPLANATION` allows only
the existing conservative `AIContextClassification.INTERNAL` classification.
Non-allowed classifications produce explicit DENY decisions without
downgrading classification. Missing or invalid Purpose/Classification fails
closed. Decisions retain the policy source reference and typed reason.

The policy does not inspect content, provider safety signals or JSON validity,
does not grant authorization or trust, and does not perform final disclosure.
