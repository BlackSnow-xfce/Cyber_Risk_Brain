# TASK-0098 – ADR: Context Resolution & Availability Semantics

Status: DONE
Review: PASS / APPROVED
Reviewer: Architect

## Architecture assessment

ADR-0016 establishes the canonical separation of:

- `EXISTS`, `REFERENCED`, `RESOLVED`, `EVALUATED` and `AVAILABLE`;
- `NO_DATA`, `NOT_APPLICABLE`, `NOT_EVALUATED`, `UNAUTHORIZED`, `STALE`,
  `ERROR` and `NOT_IMPLEMENTED`.

Resolution remains an authoritative Application-/Resolver-boundary concern.
Missing resolution fails closed to `NO_DATA`. Frontend presentation may not
simulate domain resolution. Application availability does not authorize model
egress, disclosure, trust, tools or actions.

No product implementation, test change or MVP scope change was made.
